# Conversation Summary Task

## Primary Objectives
- Create a comprehensive summary of the entire conversation history
- Perform point-by-point analysis of all discussion topics
- Structure the output as a markdown document

## Content Requirements
- Provide precise and detailed information covering all significant points
- Maintain objectivity by avoiding commentary on unresolved matters
- Include all key decisions, action items, and conclusions reached

## Output Format
- Create a well-structured markdown document named "summary.md"
- Use appropriate headers, bullet points, and formatting for readability
- Organize content chronologically or thematically, whichever best serves the material

## Special Instructions
- Focus only on explicitly stated information rather than implied meanings
- When multiple interpretations exist for undecided topics, simply note the different perspectives without editorial comment
- Include relevant timestamps or sequence information when available
